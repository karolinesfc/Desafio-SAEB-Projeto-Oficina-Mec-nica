## 📌 Sobre o projeto

O Sistema de Gestão para Oficina Mecânica foi proposto para melhorar a organização dos atendimentos e facilitar o controle das informações. A aplicação busca substituir processos manuais por recursos informatizados, tornando o gerenciamento mais prático, organizado e seguro.

## ⚙️ Funcionalidades

| Recurso | Descrição |
|---|---|
| 🔐 **Login** | Autenticação de usuários e controle de sessão. |
| 👤 **Clientes** | Cadastro, busca e edição de clientes. |
| 🚗 **Veículos** | Cadastro de veículos vinculados a clientes. |
| 📅 **Agendamentos** | Consulta de serviços agendados por data e atualização dos horários. |
| 🏠 **Tela principal** | Identificação do usuário conectado e navegação pelo sistema. |
| 🛡️ **Segurança** | Criptografia do CPF e proteção dos dados pessoais. |

## 🗄️ Banco de dados

O banco de dados organiza as informações do sistema e estabelece os relacionamentos entre usuários, clientes, veículos e agendamentos.

- Criação e população das tabelas.
- Definição de chaves primárias e estrangeiras.
- Relacionamento entre as entidades.
- Diagrama Entidade-Relacionamento (DER).
- Proteção dos dados pessoais dos clientes.

## 🔒 Segurança da informação

A segurança é um aspecto importante da aplicação. Entre os requisitos previstos estão:

- Validação das credenciais de acesso.
- Controle de sessão com tempo de expiração.
- Criptografia do CPF armazenado no banco de dados.
- Proteção de dados pessoais conforme a Lei Geral de Proteção de Dados (LGPD).

## 🎯 Objetivo

Desenvolver uma solução informatizada que facilite a rotina de uma oficina mecânica, centralizando o gerenciamento de clientes, veículos e agendamentos em um sistema organizado e seguro.
